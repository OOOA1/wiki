# Кафедра

Совместная вики для программистов и преподавателей. Интерфейс на русском, светлая и тёмная темы, адаптивная навигация.

## Возможности

- Разделы: создание, настройка значка и цвета, переименование, удаление пустых разделов.
- Статьи: визуальный редактор Tiptap, Markdown и HTML, публикации, личные черновики, теги, поиск по названию/описанию/тегам, фильтры и сортировка.
- Избранное, закреплённые статьи, история изменений, проверка версии при сохранении параллельных правок.
- Импорт `.md`, `.markdown`, `.html`, `.htm` до 500 КБ и 250 000 символов. CommonMark/GFM-совместимый парсер, проверка незакрытых блоков кода, серверная очистка HTML по разрешённому списку. Это проверка поддерживаемой разметки, а не строгий линтер всех стилей Markdown.
- Перетаскивание и загрузка PNG, JPEG, GIF, WebP до 10 МБ, MP4/WebM до 25 МБ. Вставка скриншотов из буфера обмена. Файлы хранятся в R2, метаданные и статьи — в D1.
- Одноразовые или ограниченные по числу участников токены с ролями читателя/редактора и сроком 1/7/30 дней. В базе сохраняются только SHA-256 отпечатки токенов.
- Участники входят через ChatGPT. Каждый серверный запрос проверяет членство и роль; черновики доступны автору и администратору. Отзыв приглашения не удаляет существующих участников: доступ отзывается отдельно.

## Первый вход и доступ

Новый сайт развёртывается с доступом только владельцу в Sites. Первый вошедший пользователь становится администратором вики; это безопасно только при первоначальной приватной политике Sites. Откройте сайт и завершите первый вход **до** любого расширения аудитории. После создания владельца его идентификатор фиксируется в единственной записи `wiki_settings`.

Внутренний токен не обходит внешнюю политику доступа Sites. Коллегам необходим также доступ к сайту в настройках Sites. Вики остаётся закрытой для посетителей без членства даже после входа через ChatGPT.

Восемь стартовых материалов — редактируемые примеры, явно отмеченные в интерфейсе. Они создаются один раз при первом входе владельца.

Совместная работа происходит через общую базу с обновлением списка раз в 30 секунд и при возврате на вкладку; одновременное редактирование одной статьи защищено сравнением версии. Это не редактор с живыми курсорами и слиянием символов.

## Разработка

Проект использует Vinext, React, Tailwind, Shadcn, Tiptap, Cloudflare Workers, D1 и R2. Сохраняйте pnpm и `pnpm-lock.yaml`.

Логические привязки: `DB` и `BUCKET` в `.openai/hosting.json`. Реальные ресурсы и миграции при публикации управляются Sites.

Миграции: схема в `db/schema.ts`; генерация `pnpm db:generate`; SQL и метаданные в `drizzle/` должны храниться с исходниками. Применённые миграции не меняются задним числом.

Проверки: TypeScript без ошибок; успешная сборка Worker; проверка удаления XSS, рендеринга Markdown/таблиц/кода; проверка миграции и SQL-сценариев единственного владельца, одноразового приглашения и конфликта версий.

WebMCP: условная регистрация `search_wiki_articles` и `start_wiki_article`. Проверка в браузерном контексте WebMCP не выполнялась, поскольку такой разрешённый контекст недоступен в текущем окружении. Браузерная QA не запрашивалась.
