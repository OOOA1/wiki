# Кафедра — исходники сайта

## Содержимое архива

Полный исходный код опубликованной вики, интерфейс, серверные обработчики,
редактор статей, приглашения, схема D1, миграции, стартовые материалы,
конфигурация сборки и зафиксированные зависимости.

Исходная версия: bebcb5d7a015cc772b4840b3a19522ec2ab506fd
Сайт: https://kafedra-team-wiki.selindusun7.chatgpt.site

Папка node_modules, история Git, временные файлы, секреты, пользовательские
записи из рабочей базы и загруженные пользователями файлы не включены.
Это исходники приложения, а не резервная копия его текущих данных.

## Требования

- Node.js 22.13 или новее.
- pnpm 11.25.0 (версия зафиксирована в package.json).
- Интернет для установки зависимостей.

Если pnpm не установлен:

```sh
npm install -g pnpm@11.25.0
```

## Локальный запуск

Распакуйте архив и откройте терминал в папке kafedra.

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm exec wrangler d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_short_swordsman.sql
pnpm dev
```

Откройте http://localhost:5173 . В локальном режиме кнопка входа использует
тестовую учётную запись; настоящая авторизация ChatGPT работает на Sites.
Первый локальный вход создаёт администратора и стартовые статьи.
Миграцию начальной схемы выполняйте один раз для новой локальной базы.

Команды приведены по конфигурации проекта. Отдельный запуск архива на вашем
компьютере не проверялся; сборка исходного сайта успешно выполнена.

## Размещение

Приложение рассчитано на Cloudflare Workers с D1 и R2 и интеграцией Sites.
Его нельзя запустить двойным щелчком по HTML-файлу или выложить как чисто
статический сайт.

В .openai/hosting.json сохранён идентификатор существующего сайта.
Используйте его для работы с той же вики. При создании отдельной копии
зарегистрируйте новый сайт и замените этот идентификатор.

Для размещения вне Sites потребуется настроить реальные ресурсы D1/R2
и собственную доверенную авторизацию. Нельзя принимать заголовки
о пользователе непосредственно из публичного браузерного запроса.
Первого администратора необходимо создавать в закрытом окружении.

Подробное описание возможностей и ограничений — в README.md.
